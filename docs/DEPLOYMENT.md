# Telepítés

Statikus fájlok: `index.html`, `app.js`, `games.js`, `style.css`, `assets/`, `robots.txt`. Másold a tartalmat a tárhely gyökerébe vagy a Sites esetén a `dist/` mappába. Nincs build lépés. A hash útvonalak közvetlen megnyitással működnek. Csatolás előtt ellenőrizd a valódi domaint, az üzemeltetői adatokat, a támogatási URL-t és az emberi teszt eredményét. A jelenlegi projekt még fejlesztői állapotú.
