# Projektcél

Az Aki Bújt Aki Nem magyar nyelvű, ingyenes, regisztrációmentes interaktív történetplatform. A játékok statikus fájlokból futnak; a játékosok tevékenysége nem indít AI API hívást. Az elsődleges cél az erős, újrajátszható nyomozás, nem a monetizáció.

## Korlátok

Nincs fizetős segítség, reklám, előfizetés, játékbeli vásárlás vagy kötelező fiók. A támogatási URL üres, amíg a projektgazda valódi fiókot nem ad meg. Az első publikus változatot csak szerkesztői, játékos- és jogi ellenőrzés után szabad késznek nevezni.
